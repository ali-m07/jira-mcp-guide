bash
# 1) Create a token at id.atlassian.com → Security → API Tokens
# 2) Add the connector (Claude Code example):

claude mcp add --scope user jira \
  --env JIRA_URL=https://your-company.atlassian.net \
  --env JIRA_USERNAME=you@company.com \
  --env JIRA_API_TOKEN=<API_TOKEN> \
  -- uvx mcp-atlassian
💡

برای Claude Desktop، Cursor یا VS Code، معادل JSON هر کلاینت در docs/clients.md آمده است.

bash
# 1) In Jira: Profile → Personal Access Tokens → Create
# 2) Add the connector:

claude mcp add --scope user jira \
  --env JIRA_URL=https://jira.your-company.com \
  --env JIRA_PERSONAL_ACCESS_TOKEN=<PAT> \
  -- uvx mcp-atlassian
🔐

PAT پایدارتر از OAuth است و برای سرورهای شرکتی Data Center استانداردِ رایج است.

bash
# If your team already hosts an mcp-atlassian server:

claude mcp add --scope user --transport http jira \
  https://mcp.your-company.com/mcp
🌐

در این حالت هیچ چیزی لوکال نصب نمی‌شود؛ فقط آدرس سرور را می‌دهی. اتصال با OAuth مرورگر یا هدر PAT بسته به راه‌اندازی تیم انجام می‌شود.
